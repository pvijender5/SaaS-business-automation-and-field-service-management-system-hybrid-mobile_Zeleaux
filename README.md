# Zeleaux

## 📘 Application Overview

Zeleaux is a mobile application designed to help organizations efficiently manage employee work schedules, availability, and time tracking. The system allows employees to check in and check out seamlessly while enabling administrators to monitor work patterns in real-time. The app provides a streamlined experience across both Android and iOS platforms.

## ⚙️ Tech Stack

### Frontend

* **Framework**: Flutter (Cross-platform for Android & iOS)
* **State Management**: GETX
* **Backend Communication**: RESTful API Integration
* **Authentication**: Custom API-based authentication
* **Push Notifications**: Firebase Cloud Messaging (FCM)

### Other Tools & Integrations

* **Image Upload & Compression**: `image_picker`
* **PDF/Document Handling**: `easy_pdf_viewer`
* **Maps & Location Services**: Google Maps API
